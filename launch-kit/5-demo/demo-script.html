AgriAI – 5 minute demo (judges / district administration)

Bolne wali baat "quotes" mein, click monospace mein. Sab demo PIN 2580. Demo ek phone (ya laptop par 360 px Chrome) par, screen projector/TV par mirror.

Demo se 30 min pehle (taiyari)

  1. MongoDB replica set chalu (README → "MongoDB replica set"). backend/.env mein Gemini key + DEMO_MONGO_URI=mongodb://localhost:27017/agriai_demo?replicaSet=rs0.
  2. cd backend && npm run demo:reset → "Demo taiyaar" dikhe. (Sirf agriai_demo… database reset hota hai; production/asli database par ye script mana kar deta hai.)
  3. Backend ko demo database par chalayein: MONGO_URI=$DEMO_MONGO_URI npm run dev ya .env mein MONGO_URI = demo URI. Frontend: cd frontend && npm run dev. Phone ke liye HTTPS tunnel (mic ke liye zaroori).
  4. 3 tab/profile pehle se login: A अनीता (kisan) 9000000202, B रमेश (seller) 9000000101, C संयोजक 9000000001.
  5. Phone gallery mein 2 photo: backend/seed-assets/bajra.jpg (ya asli beemar patta) aur ek gaay/mitti ki photo (unclear dikhane ke liye).
  6. Ek baar poora demo chalayein, phir dobara npm run demo:reset. Volume on (🔊). Backup: docs/screenshots/ laptop par khula rakhein.

  • Kharcha? Free tiers (Render, Atlas M0, Gemini free quota) – pilot ke liye ₹0 server; commission 3% se aage ka kharcha.
