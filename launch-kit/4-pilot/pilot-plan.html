AgriAI – 4 hafte ka pilot plan (Churu)

Kaun: 20–50 kisan, 2–3 SHG group (har group ki 1 संयोजक didi), 1 project lead (aap), KVK expert (salaah). Kahan: Churu ke 2–3 gaanv (jaise Ratangarh, Sardarshahar, Churu tehsil). Kab: Hafte 0 (taiyari) + 4 hafte.

Pilot ka sawaal: kya kisan khud photo jaanch, mausam/paani ki salaah aur bechne ke liye app use karte hain, aur kya isse unka faayda hota hai? Jawab Pilot Dashboard ki ginti + kisanon ki baat (feedback form) se milega.

Kaun kya karega

KaunZimmedari

SHG didi (संयोजक)Camp, kisan joda, seller verify, madad se listing, orders/delivery, shikayat 48 ghante, mandi gaadi, commission; roz ka checklist.

Hafte 0 – taiyari (pilot se pehle)

  • LAUNCH_CHECKLIST.md ke deploy steps; HTTPS link; npm run seed production mein kabhi nahi.
  • KVK review pass (accuracy ≥ 70%, unclear refused 100%, banned dawai 0). Fail ho to pilot aage badhayein.
  • Coordinator accounts; har SHG/gaanv ka invite code; flags: pilot features "सिर्फ़ पायलट".
  • Didi training (3-coordinator manual, 2 ghante) + ek poora test order ₹1–10 + ek mandi gaadi test.
  • Print: farmer guide (har kisan 1), poster (gaanv mein 2–3), consent form (har kisan), feedback form (×2), daily checklist (didi, 30 copy).

Kya data ikattha karein

  • Pilot Dashboard (संयोजक पैनल → पायलट डैशबोर्ड, sirf ginti) + CSV har somvaar.
  • Commission CSV (कमीशन tab), shikayat kataar ki ginti (khuli / samay nikla).
