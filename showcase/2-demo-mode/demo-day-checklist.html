Offline demo mode
Hinglish – presenter ke liye

Ek din pehle

Laptop + backup phone + power bank 100% charge; laptop charger aur extension board bag mein.
git pull, phir REBUILD=1 scripts/demo.sh ek baar (build + install sab local).
Offline test: Wi-Fi band karke scripts/demo.sh → poora demo ek baar chalayein.
Laptop par Chrome: localhost:4173, F12 → device toolbar → 360 × 780 (phone jaisa).
Demo photos phone/laptop mein: backend/demo/photos/ (sarson rust, sarson chepa, bajra jogiya) + seed-assets/handicraft.jpg ("paudha nahi").
Backup video showcase/3-video/agriai-demo.mp4 laptop + phone + pen drive par.
Deck PDF + brief PDF laptop par khule; 5 printed brief (Hindi) + 5 (English).

Venue par (30 min pehle)

Projector/HDMI test, screen mirror, font bada (Chrome zoom 125%).
scripts/demo.sh → "DEMO READY" dikhe. Internet ki zaroorat nahi.
Login check: sanyojak 9000000001, रमेश 9000000101, अनीता 9000000202 (PIN 2580).
Notifications/WhatsApp/auto-update band; phone silent; laptop sleep off.
Mobile hotspot sirf backup (asli phone par dikhane ke liye USB + chrome://inspect port forwarding).
Volume theek – 🔊 "पूरा सुनें" ek baar test.

Demo ke dauraan

Shuru mein saaf bolein: "Ye offline demo hai – AI ke asli jawab pehle record kiye gaye hain, data demo hai."
Sirf recorded photos aur sujhaye sawaal use karein (doosri photo par app "फोटो साफ नहीं" kehta hai – ye bhi dikhayein).
Bechne ka vaakya bilkul yahi: "दस क्विंटल बाजरा, पच्चीस सौ रुपये क्विंटल" + bajra.jpg.
Kuch atke → turant backup video (agriai-demo.mp4), maafi nahi, bas "recorded version dekhte hain".
Koi sankhya bina source na bolein – brief/deck ke source wali hi.
